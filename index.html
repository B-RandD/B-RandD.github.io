Executive Function backups

A personal tool that keeps sealed copies of the Executive Function app's nightly backups in its owner's own Google Drive.

What it is

Executive Function is a task and planning app that one person runs on their own computer. Each night it backs up its database and files on that computer. This tool is the last step of that backup: it seals what is new (encrypting it to the owner's public key, so that only the owner's private key, kept on paper and a USB stick, can open it) and uploads it to a folder called "Executive Function backups" in the owner's Google Drive. If the computer is ever lost, stolen or broken, the backups are still there.

Why it asks for access to Google Drive

To upload the sealed backups, the tool asks Google for one permission, drive.file: access only to the files and folder the tool itself creates. It cannot see, open or change any other file in the Drive. With that permission it:

  • creates its folder, "Executive Function backups";
  • uploads each night's sealed backup, and a copy of the small program that opens them;
  • reads back the size and checksum of what it uploaded, to make sure it arrived intact;
  • deletes an upload that arrived damaged (the backup is still on the computer, and goes again), and moves an older copy of that program to the Drive's trash.

It is not offered to anyone else: its only user is its owner, signing in to their own Google account.

Privacy

Nothing is collected or shared. The privacy policy says so in full.
